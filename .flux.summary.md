# nvim config — "clone and forget"

Location: ~/.config/nvim (macOS dev machine; also used on Linux + FreeBSD). Now a git repo (main branch, initial commit a292a79).

## Goal/contract
Clone → run nvim → everything installs itself once → forget it. Identical on Linux/macOS/FreeBSD. Zero errors/warnings by design. User left Helix to come back to nvim; wants stability over features.

## Architecture
- **init.lua**: bootstraps lazy.nvim (git clone if missing), requires vim-options + lazy.setup("plugins")
- **lua/vim-options.lua**: editor basics, leader = `,`, 2-space indent
- **lua/plugins.lua**: base plugins (plenary, fugitive, auto-pairs)
- **lua/plugins/*.lua**: one file per plugin — catppuccin (colorscheme), telescope (+ui-select), nvim-cmp (+LuaSnip, friendly-snippets), neo-tree (v3.x), lualine, colorizer, comment, conform, which-key, treesitter, lsp-config, flutter-tools

## Key decisions
- **NO mason, NO headless install scripts, NO GitHub-release downloaders** — mason breaks on FreeBSD (user's direct experience). Deleted .flux/mason-install.lua + .flux/headless-install.lua.
- **LSP = executable-guarded**: vim.lsp.config(name, {cmd=...}) + vim.lsp.enable(name) only if vim.fn.executable(cmd) — missing servers skipped silently. Modern API (nvim 0.11+), NOT the deprecated require('lspconfig') framework (breaks in lspconfig v3).
- **LSP keymaps via LspAttach autocmd** (gd/gr/K/,e/,rn/,ca), not deprecated on_attach.
- **conform**: prettier formatters only registered if binary on PATH (else format_on_save would error on every save).
- **flutter-tools**: setup() only if `flutter` executable found, else silent no-op.
- **treesitter**: new main-branch API require("nvim-treesitter").install({...}) — parsers compile from C source, works on FreeBSD (clang in base).
- **bootstrap.sh**: idempotent per-OS server installer (brew/apt/pkg + npm/gem/rustup). Servers: lua-language-server, rust-analyzer, pyright, vue-language-server, tailwindcss-language-server, solargraph, prettier; flutter opt-in via --all.
- **.gitignore**: .flux/ only.

## Verification
nvim --headless "+qa" and "+Lazy! load all" both exit 0 with zero output (no warnings). Server guard verified: rust_analyzer + flutter present on this machine; pyright etc. missing → skipped. NOTE: vim.lsp.config(name) is register-only in nvim 0.12 — read configs via vim.lsp.config["name"]; built-in configs exist for ALL servers from lspconfig, enabled state is separate.
